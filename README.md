# Algorithms and Programming

This repository contains selected exercises and assignments from the **Algorithms and Programming** course at ULPGC.

The exercises are organized by topic rather than by week, with a focus on the algorithms and programming concepts covered throughout the course.

## Topics

* Strings
* Lists
* Searching
* Sorting
* Recursion
* Data structures
* Algorithms

## Language

The exercises are currently implemented in **Python**.
